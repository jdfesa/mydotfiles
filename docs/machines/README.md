# Machine Notes

Documentacion operativa de maquinas concretas: inventario, estado de migracion,
riesgos, recuperacion y tareas pendientes.

Esta carpeta no contiene configuraciones desplegables. Las piezas reutilizables
pertenecen a `shared/` u `os/`; la seleccion para cada entorno pertenece a
`profiles/`; el inventario declarativo pertenece a `hosts/`; los valores
privados o puramente locales quedan fuera de Git.

Documentos activos:

- `main-workstation.md`: Hackintosh de produccion, protegido de experimentos;
- `lab-desktop-01.md`: Arch canary con hostname operativo `arch-desktop`.

El nombre del documento sigue la identidad fisica estable del host, no el CPU,
la distribucion instalada ni su direccion IP.
